# RayLee モバイルゲーム試作

製品設計を満たすための、自己完結した Web アプリです。タブや機能説明ではなく、宇宙を触って操作する形になっています。

## 開き方

```bash
cd /workspace/raylee-game
python3 -m http.server 8787 --bind 0.0.0.0
```

ブラウザで `http://127.0.0.1:8787/` を開きます。スマートフォンのブラウザでも、PC でも動きます（縦向きを想定）。

状態はブラウザの localStorage に保存されます。やり直しは画面右上の「試」から。

## 操作の目安（説明ではなく、中で起きること）

- 初めの聞き取りに答えると、星が生まれる。
- 宇宙をドラッグで移動、ピンチ（またはホイール）で拡大縮小、星や宝や衛星をタップ。
- 先の人の航路にある宝を、独占または分かちで受け取れる（試作の通貨「星屑」。支払いは発生しない）。
- 見守る、航路を追う、合流を申し出る、は星に対する行為。
- 右上の「✦」で自分の星へ。「◎」で宇宙をひく。
- 「試」の「夜を越える」は、いないあいだに衛星が働く様子を見るための試作操作。
